# 零、ML 基础（前置补课）

> 在深入 LLM 之前，建立扎实的机器学习底层认知

---

## 为什么需要这一章？

`llm-cookbook` 的主体内容聚焦在 **"LLM 应用层"** —— 调用现成大模型 + 工程化封装。但如果你**没有机器学习背景**，会在很多地方感到困惑：

- 什么是"训练"？为什么 LLM 能"学习"？
- 什么是 embedding？它和"词向量"有什么区别？
- 什么是 Transformer？它和 RNN / CNN 是什么关系？
- 什么是过拟合？LoRA 微调为什么需要正则化？
- TF-IDF 是什么？为什么 RAG 还需要它（不是直接用 embedding 就够了吗）？

本章用**最短的篇幅**回答这些问题，让你在阅读后续 LLM 内容时不再有"黑盒感"。

::: tip 阅读建议
本章定位是 **"前置补课"**。如果你已有 ML 背景，可以跳过；如果你完全零基础，建议**至少读完"经典机器学习"和"深度学习基础"**两章，再回到 LLM 主线。
:::

## 本章包含

### 1. [经典机器学习](./classical-ml)

> 监督/无监督学习、线性模型、决策树、聚类、特征工程、过拟合

**核心问题**：在没有神经网络之前，机器是怎么"学习"的？为什么这些方法到今天仍然重要？

### 2. [深度学习基础](./deep-learning)

> 张量、自动微分、反向传播、MLP、CNN、RNN、LSTM、优化器、正则化

**核心问题**：神经网络为什么能学？训练循环是怎么工作的？为什么 Transformer 替代了 RNN？

### 3. [NLP 经典基础](./nlp-foundations)

> 分词、TF-IDF、Word2Vec、文本分类、信息检索

**核心问题**：在 LLM 出现之前，怎么处理文本？这些方法在 RAG 时代还有用吗？

### 4. [ML 与 LLM 的关系](./ml-vs-llm)

> 演进脉络、共性原理、各自分工、何时用 ML 何时用 LLM

**核心问题**：经典 ML 和现代 LLM 究竟是什么关系？什么场景下还应该选择经典方法？

### 5. [进阶学习路径](./learning-path)

> 从 ML 基础到 LLM 微调的完整路线图

**核心问题**：本章学完后，下一步学什么？怎么走到 SFT、LoRA、DPO？

## 配套代码

每章对应 `ml_foundations/` 下的可运行 demo：

| 文档 | 配套代码 |
|------|---------|
| 经典机器学习 | `ml_foundations/classical/` —— 4 个 demo |
| 深度学习基础 | `ml_foundations/deep_learning/` —— 5 个 demo |
| NLP 经典基础 | `ml_foundations/nlp_foundations/` —— 3 个 demo |

**所有 demo 都可在 Mac CPU 上 3 分钟内跑完，无需 LLM API key**。

::: warning 安装依赖
首次运行需要安装 ML 依赖（约 1-2GB，含 PyTorch CPU 版）：

```bash
pip install -r requirements.txt
# 或仅安装 ML 部分：
pip install -e ".[ml]"
```
:::

## 推荐学习顺序

::: tip 完整路径（约 2 周）
1. **经典 ML**（2-3 天）：跑通 4 个 demo + 阅读 KNOWLEDGE.md
2. **深度学习**（4-5 天）：从 `pytorch_basics.py` 开始，依次跑通 MLP / CNN / RNN
3. **NLP 基础**（2-3 天）：跑通 3 个 demo，重点理解 Word2Vec 和 TF-IDF
4. **ML 与 LLM 的关系**（1 天）：建立全局认知
5. **进入主线**：阅读"一、LLM 基础"章节
:::

::: tip 速览路径（约 3 天）
仅阅读各章节文档（不跑代码），重点：
- 理解"什么是训练"、"什么是反向传播"
- 知道经典 ML 与 LLM 的对应关系
- 跳到主线后回头查漏补缺
:::
