# 学习路线

```
基础篇 (Week 1-2)   → LLM 原理 + LangChain 框架
RAG 篇 (Week 3-4)   → 从基础 RAG 到 CRAG/Self-RAG
Agent 篇 (Week 5-6) → ReAct + LangGraph 工作流
工程篇 (Week 7-8)   → 流式、缓存、异步、监控、容错
生产篇 (Week 9)     → 部署、安全、评估 + 高级主题
```

## 模块详情

### 一、LLM 基础（必修）

| 主题 | 你将学到 |
|------|---------|
| Transformer 架构 | 自注意力、多头注意力、位置编码、FFN |
| 文本生成 | Greedy、Beam Search、Top-K、Top-P、Temperature |
| 微调与对齐 | LoRA、QLoRA、RLHF、DPO |
| 提示工程 | Few-shot、CoT、角色设定、格式控制 |
| Tokenization | BPE 算法、Token 计数、成本计算 |
| API 调用 | 请求/响应结构、流式 SSE、上下文窗口 |

### 二、RAG 检索增强（核心）

| 主题 | 你将学到 |
|------|---------|
| RAG 基础流程 | 切分 → Embedding → 检索 → 生成 |
| Embedding 原理 | 向量空间、余弦相似度、模型选型 |
| 高级策略 | HyDE、Multi-Query、Parent-Child |
| 混合检索 | BM25 + 向量 + RRF 融合 |
| CRAG & Self-RAG | 自纠正、自反思检索增强 |
| 向量数据库 | FAISS、Chroma、索引算法、分布式 |

### 三、Agent 系统（核心）

| 主题 | 你将学到 |
|------|---------|
| Agent 架构 | 感知-推理-行动循环 |
| ReAct 框架 | Reasoning + Acting |
| Tool Calling | Function Calling、JSON Schema |
| LangGraph | 状态机、条件路由、循环 |
| HITL | 人机协作、检查点、断点续传 |

### 四、工程实践（生产必备）

| 主题 | 你将学到 |
|------|---------|
| 流式处理 | SSE、异步流、LangGraph 流式 |
| 结构化输出 | Pydantic、Function Calling |
| 异步并发 | asyncio、信号量、批处理 |
| 缓存 | 精确/语义缓存、Redis、成本优化 |
| 错误处理 | 重试、断路器、降级 |
| 可观测性 | 追踪、LangSmith、成本监控 |

### 五、生产部署

| 主题 | 你将学到 |
|------|---------|
| API 服务 | FastAPI、认证、限流、部署 |
| 安全护栏 | 注入防御、PII、红队测试 |
| 评估体系 | LLM-as-Judge、RAGAS、A/B 测试 |
