## 为什么选择 LLM Cookbook？

<div class="features-grid">

**📖 理论 + 实战双轨制**

每个模块都有教科书级知识文档 + 可运行的代码示例，理论和实践完全对应。

**🎯 系统性覆盖**

19 个知识模块，从 Transformer 底层原理到 K8s 部署，一个项目掌握全部。

**🌐 浏览器即可学习**

核心算法（BPE 分词、向量检索、注意力计算）可直接在页面运行，无需配置环境。

**📈 渐进式设计**

从 API 调用 → 框架使用 → 高级策略 → 生产部署，难度逐步递增。
