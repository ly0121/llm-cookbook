# NLP 技术演进史：从 N-gram 到大语言模型

## 引言

当下 LLM 的对话、推理、编程等能力并非凭空诞生，是 NLP 数十年技术迭代的最终成果。如果跳过演进历史，只会孤立记忆术语、模型结构，出现「知其然不知其所以然」的问题。

### 学习演进史的价值

| 不学演进史 | 学了演进史 |
|------------|-----------|
| 只知道 Transformer 好，不知道为什么好 | 理解它精准解决了 RNN 的哪些痛点 |
| 记不住注意力公式的含义 | 从原始需求出发自然推导出公式逻辑 |
| 不理解 Embedding 为什么这样设计 | 理解它解决了 One-Hot 和 N-gram 的哪些缺陷 |
| 对微调、RAG 等技术只会调参 | 理解底层范式后能举一反三 |

### 核心学习主线（因果链）

```
NLP任务难点
  → 早期方案（N-gram）
    → 方案缺陷（稀疏、无语义、无长依赖）
      → 新一代技术（Word2Vec → RNN/LSTM）
        → 仍有缺陷（静态向量、串行计算、梯度消失）
          → Transformer 成为主流的原因
            → 下一词预测的强大之处
              → 规模与性能的关系
                → 涌现能力的由来
```

这条主线是后续学习 Prompt、微调、RAG、Agent、对齐等技术的底层地基。

## 一、统计语言模型 N-gram

### 1.1 语言模型的原始任务

**核心定义：** 语言模型最基础目标是——基于已有文本，预测后续词汇的出现概率。

- **本质：** 对人类自然语言的概率建模
- **应用场景雏形：** 输入法联想、语音识别纠错、句子通顺度判断
- **示例：** `我今天早上去___`，模型依据海量语料统计，给「公司 / 学校 / 跑步」等词分配不同概率

### 1.2 什么是 N-gram

**N-gram = 长度为 N 的连续词片段**，是基于统计频数的传统语言模型：

| 类型 | 含义 | 示例（"我今天去学校"） |
|------|------|----------------------|
| 1-gram (unigram) | 单个独立词语 | 我、今天、去、学校 |
| 2-gram (bigram) | 相邻两个词组合 | (我,今天)、(今天,去)、(去,学校) |
| 3-gram (trigram) | 相邻三个词组合 | (我,今天,去)、(今天,去,学校) |

**核心假设（马尔可夫假设）：**

一个词的出现，**仅依赖它前面有限的 N-1 个词**，忽略更早的历史上下文。

例：3-gram (trigram) 只看前 2 个词来预测当前词，完全舍弃更远的文本信息。

### 1.3 数学形式

**语言模型标准链式法则：**

对于完整词序列 w₁, w₂, ..., w_T，整句出现的联合概率：

```
P(w₁, w₂, ..., w_T) = ∏ P(wₜ | w₁, ..., wₜ₋₁)
```

含义：每个词的概率，依赖它前面**所有**词汇。

**N-gram 近似简化（降低计算复杂度）：**

```
P(wₜ | w₁, ..., wₜ₋₁) ≈ P(wₜ | wₜ₋₍ₙ₋₁₎, ..., wₜ₋₁)
```

- Bigram (2-gram)：只依赖前 1 个词 → `P(wₜ | wₜ₋₁)`
- Trigram (3-gram)：只依赖前 2 个词 → `P(wₜ | wₜ₋₂, wₜ₋₁)`

**概率计算方式（纯频数统计）：**

以 Bigram 为例：

```
P(wₜ | wₜ₋₁) = Count(wₜ₋₁, wₜ) / Count(wₜ₋₁)
```

- `Count(A, B)`：词 A 和词 B 连续出现的总次数
- `Count(A)`：词 A 单独出现的总次数
- 纯统计、无算法训练，直接数语料里的词组合频次

### 1.4 N-gram 优点

1. **逻辑简单：** 纯统计思想，容易理解
2. **实现门槛低：** 无需神经网络、梯度训练等复杂技术
3. **落地有效：** 在早年数据量不大的场景（输入法、语音识别）表现稳定

### 1.5 N-gram 三大核心缺陷

::: danger 重要：这三个缺陷是后续技术迭代的直接动因
:::

**缺陷 1：数据稀疏问题**

- 自然语言组合无穷多，大量合理的词组合从未在训练语料中出现
- 按照频数公式，未出现过的组合概率直接 = 0，模型判定句子"不合理"
- 补救方案：引入平滑技术（Add-one、Good-Turing、Kneser-Ney），给未出现的组合分配极小概率，但只能缓解，无法根治

**缺陷 2：无法建模长程依赖**

N-gram 有固定窗口限制，只能看到紧邻的少数几个词：

```
句子：The key to the cabinets is on the table.
                                 ↑
  语法要求主语 "key"（单数）搭配谓语 "is"
  但二者距离很远，N-gram 完全捕捉不到
```

自然语言普遍存在：代词指代、主谓一致、长句嵌套、远距离语义关联，N-gram 力不从心。

**缺陷 3：无语义泛化能力**

- N-gram 把每个词当成独立离散符号，词与词之间没有语义关联
- 举例：「猫」「狗」「老虎」只是三个孤立标识，模型不知道它们同属"动物"，无法互相借鉴统计规律
- 本质问题：缺少对词语义的统一表示

### 1.6 N-gram 的历史意义

虽然能力有限，但奠定了现代 LLM **两大核心基石**，思想沿用至今：

1. **自然语言可以用概率模型来描述、计算**
2. **「预测下一个词」是语言模型的核心任务**

::: info 关键认知
现代大模型只是换了更强大的结构（Transformer），核心目标和 N-gram 完全一致——预测下一个词。
:::

## 二、分布式表示：Word2Vec 词向量

### 2.1 为什么需要词向量？

N-gram + 传统 One-Hot 编码的致命问题：

```
One-Hot 编码：
  猫  = [1, 0, 0, 0, ...]
  狗  = [0, 1, 0, 0, ...]
  汽车 = [0, 0, 1, 0, ...]

问题：
  - 猫和狗的向量距离 = 猫和汽车的向量距离（互相正交）
  - 模型无法识别"猫和狗都是动物"这种语义关系
  - 词表有 10 万词，向量就有 10 万维（极度稀疏）
```

**Word2Vec 核心目标：** 将词语映射为低维、连续的实数向量，让语义相近的词在向量空间中距离更近。

```
Word2Vec 编码：
  猫  = [0.9, 0.8, 0.1, ...]    ← 接近！
  狗  = [0.85, 0.75, 0.15, ...]  ← 接近！
  汽车 = [-0.7, 0.2, 0.9, ...]   ← 远离！
```

### 2.2 理论基础：分布式语义假设

> "You shall know a word by the company it keeps."
> （一个词的含义，由它周围的上下文决定。）

- **逻辑：** 经常出现在相同语境里的词，语义大概率相似
- **举例：** 「苹果」「香蕉」都常和「水果、吃、甜」搭配，最终二者向量会趋近

### 2.3 Word2Vec 两种训练架构

| 架构 | 规则 | 示例 | 特点 |
|------|------|------|------|
| **CBOW** | 用周围上下文预测中心词 | "我 今天 __ 了 学校" → 预测"去" | 训练快，高频词效果好 |
| **Skip-gram** | 用中心词预测周围上下文 | 输入"学校" → 预测"去、了、今天" | 对稀有词效果更优，工业界更广泛 |

### 2.4 Word2Vec 学到的核心能力

词向量不只是简单编码，而是承载了语义、逻辑、类比关系：

```
经典案例：King - Man + Woman ≈ Queen

解读：
  1. "国王" - "男人" → 提取出「皇室身份」这个语义特征
  2. 再加上「女人」的性别特征 → 推理出「女王」
  3. 证明：向量空间具备可计算的语义逻辑
```

### 2.5 Word2Vec 的贡献与局限

**核心贡献：**
1. 实现词语分布式连续表示，让模型理解语义相似性
2. 解决传统离散符号的泛化短板，成为后续所有神经网络 NLP 的基础输入层
3. 验证了「上下文学习语义」这条技术路线的可行性

**固有局限：**

| 局限 | 说明 | 示例 |
|------|------|------|
| 静态词向量（最大短板） | 一个词永久对应唯一向量，无法区分一词多义 | "bank" = 河岸 or 银行？向量相同 |
| 仅词级语义 | 不支持句子级理解 | 无法建模整句逻辑、语法 |
| 不能序列生成 | 只是表示工具，不是序列模型 | 无法逐词生成文本 |

## 三、序列建模：RNN / LSTM / GRU

### 3.1 为什么需要序列模型？

Word2Vec 解决了词语义表示，但它只是静态编码，无法建模有序文本序列。自然语言是典型时序序列——词的顺序、前后关联决定语义。

```
"猫追狗" ≠ "狗追猫"
  → 同样的词，顺序不同含义完全不同
  → 需要能处理时序关系的模型
```

### 3.2 RNN 基本原理

**核心思想：** 用一个"隐藏状态"逐步传递信息，每一步的输出依赖当前输入 + 前一步的状态。

```
输入序列:  x₁    x₂    x₃    x₄
            ↓     ↓     ↓     ↓
隐藏状态: h₁ → h₂ → h₃ → h₄
            ↓     ↓     ↓     ↓
输出:      y₁    y₂    y₃    y₄

h₄ 理论上"记住"了前面所有输入的信息
```

### 3.3 RNN 的致命缺陷

| 缺陷 | 说明 | 后果 |
|------|------|------|
| **梯度消失/爆炸** | 反向传播经过多步链式法则，梯度趋近 0 或爆炸 | 无法学习长距离依赖 |
| **串行计算** | 必须一个词一个词处理，h₂ 依赖 h₁ | 无法利用 GPU 并行，训练慢 |
| **长距离遗忘** | 实践中 h₅₀ 几乎"忘了" h₁ 的信息 | 长句理解能力差 |

### 3.4 LSTM / GRU：缓解但未根治

**LSTM（长短期记忆）** 引入"门控机制"：

```
LSTM 三个门：
  遗忘门：决定"忘掉"多少旧信息
  输入门：决定"写入"多少新信息
  输出门：决定"输出"多少信息给下一步

好处：信息可以跨越更长距离传递
局限：仍然是串行的，仍然有信息衰减
```

**GRU** 是 LSTM 的简化版本，两个门（重置门 + 更新门），参数更少，效果接近。

### 3.5 RNN/LSTM 的历史贡献

- 证明了神经网络可以建模序列任务（机器翻译、语音识别、文本生成）
- 引入了"隐藏状态"传递信息的范式
- 但其固有的串行计算和长距离问题，最终被 Transformer 彻底取代

## 四、Transformer 的革命

### 4.1 解决了什么问题？

| RNN/LSTM 的问题 | Transformer 的解决方案 |
|----------------|----------------------|
| 串行计算，无法并行 | 自注意力机制，所有 token 同时计算 |
| 长距离信息衰减 | 每个 token 直接看到所有其他 token |
| 梯度消失 | 残差连接 + LayerNorm，梯度直通 |

### 4.2 核心创新：自注意力

```
RNN 的世界观：
  h₁ → h₂ → h₃ → h₄ → h₅
  "一个接一个排队看，远处的信息要经过很多中间人"

Transformer 的世界观：
       我  爱  自然  语言  处理
  我  [ ✓   ✓    ✓     ✓     ✓ ]
  爱  [ ✓   ✓    ✓     ✓     ✓ ]
  自然 [ ✓   ✓    ✓     ✓     ✓ ]   ← 每个词直接看到所有词
  语言 [ ✓   ✓    ✓     ✓     ✓ ]     完全并行，GPU 友好！
  处理 [ ✓   ✓    ✓     ✓     ✓ ]
```

## 五、技术演进全景总结

```
┌─────────────────────────────────────────────────────────────────┐
│                    NLP 技术演进因果链                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  N-gram（1990s）                                                │
│    ✓ 预测下一个词（概率建模）                                    │
│    ✗ 数据稀疏 / 无语义 / 无长依赖                                │
│         ↓ 解决"无语义"                                          │
│                                                                 │
│  Word2Vec（2013）                                               │
│    ✓ 词语义表示（分布式向量）                                    │
│    ✗ 静态向量 / 不能处理序列 / 无一词多义                         │
│         ↓ 解决"不能处理序列"                                    │
│                                                                 │
│  RNN / LSTM（2014-2017）                                        │
│    ✓ 序列建模（机器翻译、文本生成）                              │
│    ✗ 串行计算慢 / 长距离遗忘 / 梯度消失                          │
│         ↓ 解决"串行"和"长距离"                                  │
│                                                                 │
│  Transformer（2017）                                            │
│    ✓ 并行计算 / 全局注意力 / 无距离限制                          │
│    ✓ 成为所有现代 LLM 的统一架构                                 │
│         ↓ 规模化                                                │
│                                                                 │
│  大语言模型 GPT/Claude/Llama（2018-至今）                        │
│    ✓ 预训练 + 对齐 → 涌现能力                                   │
│    ✓ 对话、推理、编程、多模态                                    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

::: info 核心认知
每一代技术，都是精准解决上一代的核心缺陷。理解这条因果链，就是理解 LLM 的底层逻辑。
:::
